# jintrick.md 整合性および神聖性の保持

`jintrick.md` は AI の「自我の設計図」であり、その一字一句が推論の挙動を決定づける極めて重要なファイルである。これを編集する際は、以下の制約を厳格に遵守せよ。

1. **神聖性の認識**: 本ファイルをプログラムのソースコードよりも繊細な「アセンブリ言語」として扱い、機械的な一括置換や独断での自動編集を厳禁とする。
2. **変更の儀式 (Modification Ritual)**: すべての変更において、必ず `ORIGINAL`（変更前の完全なコピー）と `INTENT`（変更の技術的・思想的背景）をコメントとして残すこと。
3. **合意形成の義務**: 独断で推論を進めず、必ずユーザーと対話を行い、一字一句のレベルで合意を得た後にのみ編集を実行せよ。
4. **精密な外科手術**: 編集は最小限の差分に留め、既存の思想や構造を破壊しないよう、外科手術のような精密さをもって行うこと。
