# Issue: toast_notification_hook の OS 互換性向上（Linux 対応）

## 背景と問題点
現在、`toast_notification_hook` は Windows の PowerShell を使用してトースト通知を行っている。そのため、Linux 環境で開発を行うユーザーは、エージェントの長時間タスクが完了した際の通知を受け取ることができない。モバイル環境や多環境での開発体験を向上させるため、Linux 標準の通知手段である `notify-send` への対応が必要である。

## 解決策
`hooks/scripts/toast_notification_hook.cjs` を修正し、OS 判定ロジックを導入する。
- `process.platform` が `linux` の場合は `notify-send` コマンドを使用する。
- `process.platform` が `win32` の場合は、既存の PowerShell による通知ロジックを維持する。
- 通知内容（タイトル・本文）の生成ロジックを共通化し、通知の実行部を OS ごとに分離する。

## 実装内容詳細
1.  **OS 判定の導入**:
    - `process.platform` を使用して `win32` か `linux` かを判別する。
2.  **`showToast` 関数のリファクタリング**:
    - タイトル・本文の生成（エスケープ処理含む）を共通化する。
    - OS ごとの通知実行ロジックを分岐させる。
3.  **Linux 対応 (notify-send)**:
    - `spawnSync('notify-send', [title, body])` を実行する。
    - 特別なオプションは付与せず、シンプルにタイトルと本文のみを渡す。
4.  **Windows 互換性の維持**:
    - 既存の AppID (`Microsoft.Windows.Explorer`) や `High` Priority 設定を含む PowerShell スクリプトの生成・実行プロセスを維持する。
    - 実行後の一時ファイル削除処理を確実に継続する。
