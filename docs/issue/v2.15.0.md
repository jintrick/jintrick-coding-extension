# Issue: Optimize command_fixer_hook.cjs for PowerShell 7 and implement dynamic POSIX-to-PS alias conversion.

## 背景と問題点
現在の `command_fixer_hook.cjs` は PowerShell 5.1 互換性のために `&&` を `;` に置換しているが、モダンな環境（PowerShell 7）では `&&` が標準サポートされている。
また、AI が生成する POSIX コマンド（`rm -rf`, `mkdir -p`, `which` 等）は、PowerShell のエイリアスやフラグの挙動（例：`-rf` は `-Recurse -Force`）と乖離があり、実行エラーや予期せぬ挙動を招く原因となっている。

## 解決策
- `command_fixer_hook.cjs` における `&&` から `;` への置換ロジックを削除し、PowerShell 7 のネイティブな動作を許容する。
- 以下の POSIX コマンドに対する動的な PowerShell 変換ロジックを実装する。
  - `rm` -> `Remove-Item` (特に `-rf` を `-Recurse -Force` に)
  - `mkdir` -> `New-Item -ItemType Directory` (特に `-p` 対応)
  - `cp` -> `Copy-Item` (特に `-r` 対応)
  - `ls` -> `Get-ChildItem`
  - `which` -> `Get-Command`
- コマンドの誤置換を防ぐため、正規表現を用いて「行頭」または「セパレータ（`;`, `&&`, `||`, `|`）」直後のコマンドのみを対象とする。

## 実装内容詳細
- **&& 置換の削除**:
  - `originalCommand.replace(/ && /g, ' ; ')` を削除。
- **動的変換エンジン**:
  - `replaceCommands(commandString)` 関数を実装。
  - セパレータで分割するか、またはグローバルな正規表現 `/((?:^|[;&|])\s*)(rm|mkdir|cp|ls|which)(\s+.*?(?=[;&|]|$))/g` を使用して、コマンドと引数を抽出。
  - 引数内のフラグを置換するサブロジックを実装。
    - `rm`: `-rf` -> `-Recurse -Force`, `-f` -> `-Force`, `-r` -> `-Recurse`
    - `mkdir`: `-p` -> (特になし。PowerShellの `New-Item -ItemType Directory -Force` が相当)
    - `cp`: `-r` -> `-Recurse`
- **バリデーション**:
  - 文字列リテラル内や、他の単語の一部としてのコマンド（例：`storm` の `rm`）は置換しないよう、`\b` やセパレータの存在を厳格にチェックする。

## 規約準拠 (Rule Compliance)
- `comment-preservation.md`: 既存の JSDoc および変換ロジックの背景を説明するコメントを、PowerShell 7 前提の内容に更新して維持する。
- `no-temp-files-in-root.md`: 本フックはメモリ内での文字列操作のみを行うため、一時ファイルは作成しない。

## ゴール
- [ ] `&&` を含むコマンドが、そのまま PowerShell 7 でショートサーキットとして実行される。
- [ ] `rm -rf <path>` が `Remove-Item -Recurse -Force <path>` に置換され、エラーなく動作する。
- [ ] `mkdir -p <path>` が `New-Item -ItemType Directory -Force -Path <path>` 等の等価なコマンドに置換される。
- [ ] `which <cmd>` が `Get-Command <cmd>` に置換される。
- [ ] 意図しない箇所（文字列内、単語の一部）での置換が発生しない。

## テスト
- **テスト対象**: `hooks/scripts/command_fixer_hook.cjs`
- **テスト内容・目的**: 新しい置換ロジックが期待通りに動作し、かつ `&&` が維持されることを確認する。
- **検証方法・手順**:
  - `npm test tests/hooks/command_fixer_hook.test.js` を実行。
  - 以下のケースをカバーするテストコードを追加：
    - [ ] `rm -rf test` -> `Remove-Item -Recurse -Force test`
    - [ ] `mkdir -p a/b/c` -> `New-Item -ItemType Directory -Force -Path a/b/c`
    - [ ] `cp -r src dest` -> `Copy-Item -Recurse src dest`
    - [ ] `ls -la` -> `Get-ChildItem` (フラグ調整含む)
    - [ ] `which node` -> `Get-Command node`
    - [ ] `git add . && git commit` (置換なし)
    - [ ] `echo "rm -rf"` (クォート内は置換なし)
    - [ ] `storm` (単語内は置換なし)
