# Issue: `command_fixer_hook.cjs` における環境依存のコマンド変換ロジックの実装

## 背景
現在、`hooks/scripts/command_fixer_hook.cjs` は、実行環境に関わらず POSIX コマンド（rm, mkdir, cp, ls, which）を PowerShell コマンドへ強制的に変換しています。
これにより、Linux Mint 等の POSIX ネイティブな環境において、正しいシェルコマンドが PowerShell コマンドに誤変換され、実行に失敗する不具合が発生しています。

## 修正内容
- `command_fixer_hook.cjs` 内で実行環境（OS）を判定するロジックを追加する。
- 実行環境が Windows 以外（Linux, Darwin 等）である場合は、コマンドの置換処理をスキップし、オリジナルのコマンドをそのまま許可する。
- ユニットテストにおいて、環境別の動作（Windows では変換、Linux では変換なし）を検証するケースを追加または修正する。

## 設計上の考慮点 (Coding Rules)
### comment-preservation.md
- OS 判定ロジックの追加に伴い、変換処理が Windows 限定であることの意図を JSDoc またはコメントで明記する。
- 既存のコマンドマップに関するコメントを維持しつつ、プラットフォーム依存 babysat の制約を追記する。

### no-temp-files-in-root.md
- 今回の修正ではファイル操作を行わないが、将来的にデバッグ目的などで一時ファイルを出力する必要が生じた場合は、OS 標準の一時ディレクトリを使用すること。

## アトミックな実装手順
1.  **環境判定の導入**: `hooks/scripts/command_fixer_hook.cjs` の `main` 関数冒頭で、`process.platform` が `win32` 以外の場合に即座に `allow()` を返すガード節を追加する。
2.  **テストコードの拡充**: `tests/hooks/command_fixer_hook.test.js` に `process.platform` を `linux` にモックした状態でコマンドが変換されないことを検証するテストケースを追加する。
3.  **ビルドの実行**: `npm run build` を実行し、`dist/hooks/command_fixer_hook.cjs` に変更を反映させる。
4.  **検証**: `npm test` を実行し、既存の Windows 向け変換テストと新規追加の非 Windows テストがすべてパスすることを確認する。
