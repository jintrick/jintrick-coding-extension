# Issue: システムプロンプト更新検知の要件完遂とフック通知のノイズ低減 (v2.6.1)

## 1. 概要
`v2.6.0` で実装されたシステムプロンプト監視機能を改善し、検知したプロンプトを `tech-expert` スキルとして活用可能にする。また、起動時のフックによる警告アイコン（⚠）の露出を抑え、ユーザー体験を最適化する。

## 2. 背景
現在の実装では以下の課題がある：
1.  **知識の未統合**: 抽出されたシステムプロンプトが `tech-expert` スキルに組み込まれておらず、エージェントが自らの仕様を検索できない。
2.  **冗長な通知**: 記録済みのバージョンであっても「already recorded」と表示され、起動のたびに警告アイコン（⚠）が出るのがノイズである。
3.  **差分の不明瞭さ**: バージョンアップ時に何が変わったのかが通知されず、単に「更新された」ことしかわからない。

## 3. 解決策
1.  **Skill 昇格の有効化**: `tools/build.cjs` を修正し、`knowledge/system_prompt/` を `tech-expert-system_prompt` スキルとしてビルド・デプロイ対象に含める。
2.  **監視フックのサイレント化**: すでに記録済みのバージョンの場合は `systemMessage` を返さないようにし、起動時のノイズを排除する。
3.  **技術スタック検出の最適化**: `tech_stack_discovery_hook.cjs` のメッセージ表示条件を整理し、不要な警告を抑制する。

## 4. 実装内容詳細
### 4.1. 対象ファイル
- `tools/build.cjs`: `system_prompt` ディレクトリのスキップ処理を削除。
- `hooks/scripts/system_prompt_monitor_hook.cjs`: 記録済み時の `systemMessage` 削除、および新バージョン検知時の通知強化。
- `hooks/scripts/tech_stack_discovery_hook.cjs`: メッセージ出力ロジックの改善。

### 4.2. ロジック変更
- **Build**: `knowledge/` 内の各バージョンディレクトリを `tech-expert-system_prompt` の `references/` へ配備し、`catalog.json` を生成。
- **Monitor**: `fs.existsSync(originalPath)` が真の場合、JSON レスポンスから `systemMessage` を除外して `decision: "allow"` のみを返す。

## 5. ゴール (Definition of Done)
- [ ] `npm run build` 後、`skills/tech-expert-system_prompt/` が正しく生成されている。
- [ ] プロンプトに変更がない通常の起動時、`Hook system message` が表示されない（または大幅に低減されている）。
- [ ] `tech-expert` サブエージェント経由で、過去および現在のシステムプロンプトの内容を照会できる。
