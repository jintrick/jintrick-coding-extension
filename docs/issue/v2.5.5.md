# Issue: Python Linter Fix (lambda and escape sequences)

## 概要 (Overview)
Python Linter (`py.cjs`) において、lambda 関数の引数が未定義の変数として誤検知される問題と、文字列内の `\n` が SyntaxError を引き起こす問題を修正する。

## 背景 (Background)
- 現状、Linter は lambda のスコープを適切に処理しておらず、引数が外部スコープで定義されている必要があると誤認している。
- また、ファイル書き込み前に `\n` などのエスケープシーケンスを物理的な改行に置換する処理が含まれており、これが Python の `ast.parse` に渡された際に文字列の不整合（クォートの不一致など）を引き起こしている。

## 修正内容 (Changes)
### 1. Python Linter (`hooks/scripts/linters/py.cjs`)
- `ast.Lambda` のハンドラを追加し、引数をローカルスコープとして正しく扱うように修正。
- `content.replace(/\\n/g, '\n')` などの誤ったエスケープ置換処理を削除。

## 成功基準 (Success Criteria)
- [x] lambda 関数を含む Python コードが Linter でパスすること。
- [x] 文字列内に `\n` を含む Python コードが Linter でパスすること。
- [x] 実際に未定義の変数が含まれる場合は適切にエラーを検知すること。
- [x] `tests/reproduce_py_linter_issue.test.mjs` で全てのテストがパスすること。
