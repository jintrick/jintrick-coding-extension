# Issue: システムプロンプト統合と動的リマインダーによるルール遵守の強化

## 概要
`GEMINI_SYSTEM_MD` によるプロジェクト憲法の定義と、`BeforeModel` フックによる動的リマインダー（System Reminder）を組み合わせ、モデルにプロジェクト規約を忘却させない強固な統治環境を構築する。

## 成果物 (Outputs)
- `hooks/scripts/system_prompt_builder.cjs` (SessionStart 専用: system.md 生成)
- `hooks/scripts/system_reminder_hook.cjs` (BeforeModel 専用: リマインダー注入)
- `${CWD}/.gemini/system.md` (生成された憲法ファイル)
- `hooks/hooks.json` (フック登録の更新)

## 受け入れ基準 (Acceptance Criteria)

### AC1: 憲法 (system.md) の自動生成
- [ ] `SessionStart` フックにおいて、`.agent/rules/*.md` をスキャンし、メタデータを抽出すること。
- [ ] `always_on` ルールの全文と `glob` ルールのインデックス（Glob・説明）を埋め込んだ `.gemini/system.md` を生成すること。

### AC2: 動的リマインダーの注入 (BeforeModel)
- [ ] `BeforeModel` フックにおいて、モデルに送信される `messages` 配列の最後（最新のユーザー入力の直後）に、以下の役割を持つリマインダーを注入すること。
  - 内容：「リマインダー：常に `.agent/rules/` の規約を遵守せよ。関連ルールは自ら `read_file` して確認せよ。」
- [ ] 毎ターン確実に注入し、履歴の増大に伴う規約の忘却を物理的に防ぐこと。

### AC3: パフォーマンス制約
- [ ] `BeforeModel` でのリマインダー注入処理：**5ms 以内**。
- [ ] `SessionStart` での `system.md` ビルド処理：**100ms 以内**。

## テスト手順 (Test Steps)
1. `.agent/rules/` にルールを作成。
2. `$env:GEMINI_SYSTEM_MD=1; gemini` で起動。
3. 最初の質問を投げ、モデルが「規約の存在」と「リマインダーの内容」を認識していることを確認。
4. 長い会話を続け、ターンの後半でも規約が遵守され続けることを確認。
