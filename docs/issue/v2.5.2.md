# Issue: Reduce Context Consumption by Removing README.md from Extension Context

## 1. 現状の課題 (Problem Statement)
`gemini-extension.json` の `"contextFileName": "README.md"` 指定により、拡張機能使用時に `README.md` の全内容がコンテキストに注入され、トークンを無駄に消費している。

## 2. 修正方針 (Proposed Changes)
- `gemini-extension.json` から `"contextFileName": "README.md"` を削除、または空文字にする。
- `README.md` の内容を精査し、開発者向けドキュメント（IDDフロー等）を `docs/reference/` 等へ移行済みであれば、ユーザー向けに必要な最小限の記述（インストール方法等）のみに絞る。

## 3. 実装計画 (Implementation Plan)
1. `gemini-extension.json` の `contextFileName` を削除。
2. `README.md` の内容を削減。
3. `npm run build` を実行。
4. 動作確認（不要なコンテキストが注入されていないことの確認）。

## 4. 影響範囲 (Impact)
- 全セッションの初期コンテキストが軽量化される。
- ユーザーが `README.md` の内容を必要とする場合、手動で参照する必要が生じる。
