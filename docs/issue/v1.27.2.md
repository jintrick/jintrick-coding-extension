# Issue: tech-expert エージェントのモデルを gemini-3-flash-preview に固定

## 概要
`tech-expert` サブエージェントが使用する AI モデルを、明示的に `gemini-3-flash-preview` に指定する。

## 背景と問題点
現在、サブエージェントのモデルは `inherit`（メインセッションのモデルを継承）となっており、ナレッジ抽出のような特定のタスクに最適化されたモデルを選択できていない可能性がある。

## 解決策
`agents/tech-expert.md` のフロントマターに `model: gemini-3-flash-preview` を追加する。

## 実装内容詳細
- `agents/tech-expert.md` の修正。

## ゴール
- `tech-expert` サブエージェントが起動した際、指定されたモデルが利用されること。
