# Issue: v2.5.3 - Disable Automatic Extension Context Loading

## 背景
`jintrick-coding-extension` を `gemini extensions link .` でインストールしている場合、拡張機能のルートディレクトリにある `GEMINI.md` が、Gemini CLI の仕様により全セッションのコンテキストに自動注入されてしまう。
これにより、他の無関係なプロジェクト（例: `shiftmaker`）での作業中に、本拡張機能用の指示が混入し、モデルの挙動に悪影響を与える可能性がある。

## 目的
拡張機能のルートにある `GEMINI.md` が自動ロードされないようにし、拡張機能のコンテキストを明示的に制御する。

## 設計
1. `gemini-extension.json` の `contextFileName` プロパティを利用して、デフォルトの `GEMINI.md` 探索を回避する。
2. 存在しないファイルを指定するのではなく、「存在するが空のファイル」を指定することで、仕様に基づいた安全な無効化を行う。

## タスク
- [x] 空のコンテキストファイル `.gemini-context-empty.md` を作成。
- [x] `gemini-extension.json` の `contextFileName` に `.gemini-context-empty.md` を指定。
- [x] 既存の `GEMINI.md` は、開発用のドキュメント（または将来的な明示的ロード用）として保持する。

## 検証
- `/memory show` を実行し、`jintrick-coding-extension/GEMINI.md` がロードされていないことを確認。
