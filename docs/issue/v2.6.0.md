# Issue: Gemini CLI 更新検知およびシステムプロンプト自動抽出フックの実装

## 1. 概要
Gemini CLI のバージョンアップを `SessionStart` イベントで自動検知し、システムプロンプト（Mandates等）に変更があった場合に最新のプロンプトを抽出・正規化してアーカイブするとともに、ユーザーに通知する Hook を実装する。

## 2. 背景
CLI のバージョンアップによりシステムプロンプトが変更されると、エージェントの基本挙動（セキュリティ要件やワークフロー）が変わる可能性がある。これを手動で追うのは困難なため、拡張機能側で自動的に「正解（Expected）」を抽出し、過去のバージョンと比較・管理できる体制を整える。

## 3. 解決策
`SessionStart` フック `system_prompt_monitor_hook.cjs` を実装する。
このフックは、インストール済みの CLI バージョンを確認し、未記録のバージョンの場合にプロンプトの抽出・正規化を実行して `knowledge/system_prompt/vX.Y.Z/original.md` を生成する。

## 4. 実装内容詳細
### 4.1. 対象ファイル
- `hooks/scripts/system_prompt_monitor_hook.cjs` (新規作成)
- `knowledge/system_prompt/` (プロンプト履歴ストレージ)
- `hooks/hooks.json` (フック登録)
- `tools/build.cjs` (ビルド対象追加)

### 4.2. ロジック構成
1.  **バージョンチェック**:
    - `gemini --version` で現在のバージョンを取得。
    - `${extensionPath}/knowledge/system_prompt/v${version}/original.md` の存在を確認。
2.  **更新検知時の処理** (ファイルが存在しない場合):
    - **抽出**: `npm root -g` から CLI コアの `snippets.js` を特定し動的にインポート。`getCoreSystemPrompt(options)` を呼び出し、生のプロンプトを生成。
    - **正規化**: 以下の加工を行い、`original.md` として保存。
        - `<available_subagents>...</available_subagents>` 内を `${SubAgents}` に置換。
        - `<available_skills>...</available_skills>` 内を `${AgentSkills}` に置換。
        - **ユーザーコンテキストセクションの除去**: `# Contextual Instructions (GEMINI.md)` から始まり、`<loaded_context>...</loaded_context>` タグの終わりまでを削除。
        - **改行の整理**: 3つ以上の連続する改行を2つに整理。
    - **通知**: `systemMessage` を使用して「System Prompt Updated to v${version}」とユーザーに報告する。

### 5. ゴール (Definition of Done)
- [ ] CLI更新後の初回セッションで、`knowledge/system_prompt/vX.Y.Z/original.md` が自動生成される。
- [ ] 生成される `original.md` が、プレースホルダー化および不要セクション削除により正規化されている。
- [ ] 既存の記録済みバージョン（v0.35.3等）については再処理を行わず、スキップする。
- [ ] 更新検知時に、保存先パスを含む通知（systemMessage）がユーザーに表示される。

### 6. 技術的制約 (Technical Constraints)
- [ ] **ディレクトリ非依存**: どのプロジェクトディレクトリ（cwd）から実行しても、拡張機能内の `knowledge/` を正しく特定し、書き込みができること。
- [ ] **低負荷・オフライン**: `snippets.js` の抽出プロセスにおいて、Gemini CLI のメインロジック（ネットワーク通信やUI描画）を一切起動せず、純粋な文字列生成のみを行うこと。
- [ ] **堅牢性**: 環境エラー（npm root失敗等）時にセッション開始をブロックせず、エラーログを出力して正常にフォールバック（allow）すること。
