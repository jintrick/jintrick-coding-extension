# Issue: ビルド時のスキル生成におけるバージョン番号を日付形式 (YYYY-MM-DD) に変更

## 概要
`knowledge/` からスキルを自動生成する際、バージョン番号が固定の `1.0.0` であった。これを日付形式に変更し、ビルド時の履歴を明確にする。

## 背景と問題点
固定のバージョン番号では、スキルの更新タイミングや最新性が不明瞭であるため。

## 解決策
`tools/build.cjs` にて現在日付を取得し、`manifest.json` と `SKILL.md` の生成時に適用する。

## 実装内容詳細
- `tools/build.cjs` に `CURRENT_DATE` 定数を追加。
- `manifest.json` の `version` プロパティを `CURRENT_DATE` に変更。
- `SKILL.md` の自動生成および補完ロジックにおけるバージョンを `CURRENT_DATE` に変更。

## ゴール
- ビルド後の `dist/skills/tech-expert-*/` 内のファイルが `YYYY-MM-DD` 形式のバージョンを持つこと。
