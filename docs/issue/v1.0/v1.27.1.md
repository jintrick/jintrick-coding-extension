# Issue: ナレッジの検知ルール生成における最終フォールバックの廃止とエラー化

## 概要
`tools/build.cjs` において、`detector.json` も推論用のファイル（`package.json` 等）も見つからない場合に作動していた最終フォールバック（`<stack>.config.js` を検知ルールとする推測）を廃止し、明示的なエラーを投げてビルドを停止させるよう修正する。

## 背景と問題点
- **不確実な推測**: `react.config.js` のような、存在しないことが多いファイルを最終フォールバックとして自動設定するのはハルシネーションと同義であり、不具合の温床になる。
- **エラーの隠蔽**: ナレッジ追加者が `detector.json` を配置し忘れてもビルドが通ってしまい、実行時になって初めて「ナレッジが読み込まれない」という問題に直面する。これをビルド時のエラー（Fail Fast）として検知すべきである。

## 解決策
- `tools/build.cjs` の `promoteKnowledge` 関数内の最終フォールバックブロックを削除。
- `detectors.length === 0` のままになった場合、`throw new Error(...)` を実行し、どのナレッジディレクトリで `detector.json` が欠如しているかを開発者（エージェント）に伝える。

## 実装内容詳細
- `tools/build.cjs` の修正。
- 関連するテスト（`tests/detector_json.test.js`）の更新（エラーがスローされることの検証）。

## ゴール
- 検知条件が空のナレッジをビルドしようとした際、ビルドプロセスが明確なエラーメッセージと共に異常終了（Exit Code 1）すること。
