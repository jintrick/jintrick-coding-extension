# Issue: MySQL2 ナレッジの detector.json 追加とビルドエラーの解消

## 概要
`knowledge/mysql2` に `detector.json` が欠けていたため、ビルド時の安全機構（v1.27.1）によりビルドが停止した問題を修正。

## 背景と問題点
`mysql2` ナレッジディレクトリ内に検知用のメタデータファイルが存在しなかったため、`tools/build.cjs` が検知ルールを生成できずエラーをスローした。

## 解決策
`knowledge/mysql2/detector.json` を作成し、`npm: "mysql2"` を指定する。

## 実装内容詳細
- `knowledge/mysql2/detector.json` の作成。
- `npm run build` による再ビルド。

## ゴール
- ビルドが正常に完了し、`dist/skills/tech-expert-mysql2` が正しく生成されること。
