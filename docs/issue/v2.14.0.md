# Issue: `init-jintrick-project` スキルの実装と同期機構の構築

## 目的
jintrick開発プロジェクトの初期化を自動化するスキルを実装する。また、プロジェクトルートとスキル内の `system.md` を最新状態に維持する同期パイプラインを構築する。

## 出力成果物
- 新規ディレクトリ: `skills/init-jintrick-project/`
- 新規ファイル: `skills/init-jintrick-project/scripts/init_project.cjs`
- 新規ファイル: `tools/sync_system_prompt.cjs`
- 更新ファイル: `tools/jintrick_to_system.cjs`, `tools/build.cjs`, `gemini-extension.json`

## 完了条件 (DoD)
- [ ] `gemini-extension.json` にスキルが登録されている
- [ ] `skills/init-jintrick-project/assets/` に `package.json`, `.agent/rules/`, `.gemini/system.md` が配備されている
- [ ] `init_project.cjs` を実行した際、空ディレクトリにアセットがコピーされる
- [ ] `init_project.cjs` を実行した際、既存の `package.json` がある場合は処理が中断される（上書きされない）
- [ ] `init_project.cjs --force` を実行した際、既存ファイルが上書きされる
- [ ] `npm run build` を実行した際、`.gemini/system.md` と `skills/init-jintrick-project/assets/.gemini/system.md` の両方が更新される
- [ ] テスト `tests/skills/init-jintrick-project.test.js` がパスする

## 実装仕様

### 1. スキル構造
以下の構造を生成する：
- `SKILL.md`: 初期化スキルの使用手順を記述する
- `assets/package.json`: Jintrick開発フローにおけるバージョン確認の基準となるため、`"version"` フィールドを必須とする。その他 `"type": "module"`, `scripts` (test/build/issue-sync) を含む基本テンプレート。
- `assets/.agent/rules/`: `comment-preservation.md`, `no-temp-files-in-root.md` のコピー
- `assets/.gemini/system.md`: ビルド生成物（手動編集禁止）
- `scripts/init_project.cjs`: 初期化ロジック

### 2. 初期化スクリプト (`init_project.cjs`)
**制約: Idempotent (冪等性)**
- 入力: 実行時カレントディレクトリ
- 処理: `assets/` 配下の全ファイルをカレントディレクトリへコピーする
- 競合検知: コピー先ファイルが既に存在する場合はエラー終了する
- 上書き: コマンドライン引数 `--force` が指定された場合のみ既存ファイルを上書きする

### 3. 同期スクリプト (`tools/sync_system_prompt.cjs`)
**制約: Atomic (単一責務)**
- 処理: 入力された文字列（またはファイル）を、複数の指定パス（`.gemini/system.md` および `skills/init-jintrick-project/assets/.gemini/system.md`）へコピー・配備する
- 拡張性: 今後実装予定の「タイムスタンプ比較ロジック」を組み込める独立したモジュールとして設計する

### 4. 変換スクリプト (`tools/jintrick_to_system.cjs`)
- 処理: `jintrick.md` のフォーマット整形とコメント削除のみを行う
- 連携: 変換完了後、生成文字列を `sync_system_prompt.cjs` に渡し、同期を委譲する

### 5. ビルド統合 (`tools/build.cjs`)
- 処理: ビルドプロセスの一環として `jintrick_to_system.cjs` を起動し、全環境の `system.md` を最新化する

## 制約・禁止事項と代替行動

| 禁止 | 代替行動 |
|------|----------|
| 一時ファイルをプロジェクトルートに作成する (`no-temp-files-in-root.md`) | `tests/tmp/` または OS の一時ディレクトリを使用する |
| 意図を説明するコメントを削除する (`comment-preservation.md`) | フォーマット変更時も元のコメント行を維持する |
| 抽象的な推測で `package.json` に依存関係を追加する | 最小構成（最小限の `scripts` と `type: module`）に留める |

## テスト要件
ファイル: `tests/skills/init-jintrick-project.test.js`
- モックファイルシステム（または分離された一時ディレクトリ）を使用する
- **Case 1**: 空ディレクトリへの配備が成功する（Exit Code 0）
- **Case 2**: `package.json` が存在するディレクトリでの配備がエラー中断する（Exit Code > 0）
- **Case 3**: `package.json` が存在しても `--force` 引数指定時は上書き成功する（Exit Code 0）
