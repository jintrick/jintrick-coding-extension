# Issue: .agents/rules/*.md の記述標準化のための agent-rules-expert スキルの追加

## 概要
AIエージェントがプロジェクト固有のルールやコンテキストを参照するための `.agents/rules/*.md` ファイルの記述を標準化し、その作成・保守を支援する専門スキル `agent-rules-expert` を追加する。

## 背景と問題点
- 本プロジェクトでは `.agents/rules/*.md` を用いてエージェントへの追加制約を定義しているが、その記述形式や粒度が標準化されていない。
- `prompt_crafter` スキルは `agent-document-spec.md`（一般的なプロンプト設計）を扱うが、`.agents/rules/` ディレクトリ特有の構造や運用ルールに特化した専門知識が不足している。
- 新しいルールを追加する際、既存の設計原則（抽象語の排除、成果物拘束など）が徹底されにくい。

## 解決策
- 新しいスキル `agent-rules-expert` を定義する。
- `.agents/rules/*.md` のための設計仕様（`rules-spec.md`）を策定し、スキルに同梱する。
- `prompt_crafter` の原則を継承しつつ、プロジェクト固有の制約（ディレクトリ構成、ファイル命名規則、適用スコープの定義方法）を明文化する。

## 実装内容詳細
1. **スキルディレクトリの作成**:
   - `skills/agent-rules-expert/` を作成。
2. **SKILL.md の作成**:
   - ルール作成時のペルソナ（Rule Architect）と、`rules-spec.md` を活用した指示を記述。
3. **リファレンスドキュメントの作成**:
   - `skills/agent-rules-expert/references/rules-spec.md` を作成し、以下の項目を定義：
     - ファイル命名規則（例: `topic-standard.md`）
     - 必須セクション（Fact, Mandate, Action, Examples 等）
     - 記述の禁止事項（抽象表現の禁止、代替行動の明示）
4. **既存エージェントとの連携**:
   - `issue-crafter` 等がルールを新規作成・更新する際に、このスキルを `activate_skill` できるようにする。

## ゴール

- [ ] `skills/agent-rules-expert/references/rules-spec.md` が作成されていること
