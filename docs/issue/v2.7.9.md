# Issue: issue-crafter の責務変更（ファイル作成権限の剥奪）

## 背景と問題点
`issue-crafter` が Issue 文書を直接ファイルとして作成（`write_file`）すると、メインエージェントのコンテキスト（記憶）とディスク上のファイル状態が乖離する。結果としてメインエージェントが規約違反（`cat`コマンドの使用等）を引き起こす根本原因となっていた。

## 解決策
`issue-crafter` からファイル作成権限（`write_file`, `replace`）を剥奪し、Issue 文書のドラフトをテキストで提示するだけの責務に変更する。ファイルへの書き込みとコミットはメインエージェントが明示的に引き継ぐことで、IDDフローとCI/CDパイプラインを正常に機能させる。

## 実装内容詳細
1. `agents/issue-crafter.md` の `tools` から `write_file` と `replace` を削除。
2. 指示内容を「完全なマークダウン形式の Issue 文書案を生成し、テキストで提示せよ」に変更。

## ゴール
`issue-crafter` がファイルを作成せず、メインエージェントにドラフトを提示する状態になること。

## テスト
- `npm run build` が通ること。
- `npm test` が通ること。
