# Epic: Antigravity 互換・動的プロンプト・コンパイラの構築

## 最終ゴール
Gemini CLI において、Antigravity 由来のルール・トリガー・システム（trigger: glob|always_on|manual|model_decision）を実装し、カレントワーキングディレクトリ（CWD）や現在のコンテキストに最適化されたシステムプロンプトの動的合成を実現する。

## コア・アーキテクチャ (Constraints & Design)
- **フロントマター・スキーマ (Source of Truth)**:
  - `trigger`: `always_on`, `glob`, `manual`, `model_decision` のいずれか。
  - `description`: ルールの説明。
  - `globs`: 適用対象のパスパターン。
- **イベント駆動型インデックス管理**:
  - `SessionStart`: ワークスペースのフルスキャンとキャッシュ構築（再起動ベースの同期）。
- **インジェクション・パフォーマンス**:
  - `BeforeModel`: キャッシュ（JSON）の読み込みと注入のみを行い、ファイル走査は厳禁とする。10ms 以内の応答速度を維持する。
- **ワークスペース分離**: インデックスは各プロジェクトの `${process.cwd()}/.gemini/cache/rule-index.json` に保存し、マルチワークスペースでの競合を防ぐ。
