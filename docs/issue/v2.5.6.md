# Issue: 対話セッションを起動せずにシステムプロンプトを抽出するスクリプトの作成

## 1. 概要
Gemini CLI（v0.35.3以降）の対話セッション（モデル接続）を開始することなく、標準のシステムプロンプトを静的なファイルとして抽出するための専用スクリプト `tools/generate-system-prompt.cjs` を実装する。

## 2. 背景
現在の `GEMINI_WRITE_SYSTEM_MD=1` 環境変数による出力機能は、CLIの完全な起動を伴うため、対話画面の表示やモデルへの接続確認を回避できない。プロンプトのテンプレートのみを純粋に取得・管理するために、公式のレンダリングエンジン（`snippets.js`）を流用したスタンドアロンな抽出手段を構築する。

## 3. 解決策
インストール済みの公式 `snippets.js` を `require` して実行するスクリプトを作成する。
その際、特定のレンダリング関数をランタイムで上書き（モック）することにより、実行時の動的コンテキストを排除し、必要なプレースホルダーを維持した状態のテンプレートを生成する。

## 4. 実装内容詳細
### 4.1. 対象ファイル
- `tools/generate-system-prompt.cjs` (新規作成)

### 4.2. ロジック構成
1.  **公式エンジンのロード**:
    - 以下のパスにある `snippets.js` を `require` する。
    - `C:/Users/Jintrick/AppData/Roaming/npm/node_modules/@google/gemini-cli/node_modules/@google/gemini-cli-core/dist/src/prompts/snippets.js`
2.  **jintrick's Mandates (レンダリング関数の上書き)**:
    - `snippets.renderSubAgents`: 変数展開を停止し、文字列 `${SubAgents}` をそのまま返す。
    - `snippets.renderAgentSkills`: 変数展開を停止し、文字列 `${AgentSkills}` をそのまま返す。
    - `snippets.renderUserMemory`: `<loaded_context>` を含めないよう、常に空文字列 `''` を返す。
3.  **標準オプションの適用**:
    - `getCoreSystemPrompt(options)` に渡す `options` は、標準的なインタラクティブセッション（`interactive: true`, `gitRepo: true`, `hasSkills: true` 等）を再現する構成とする。

### 4.3. 期待される出力例
- ファイル冒頭から `# Core Mandates` 等の公式定義が正しく出力されること。
- ツール名（`grep_search`, `read_file` 等）が実体名で展開されていること。
- 出力内に `${SubAgents}` と `${AgentSkills}` がプレースホルダーとして存在すること。
- `<loaded_context>` およびその関連タグが一切含まれないこと。
