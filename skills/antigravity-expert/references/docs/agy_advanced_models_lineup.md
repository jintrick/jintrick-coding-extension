# Antigravity Reasoning Model Lineup

The agent can switch between different frontier models depending on the task's complexity.

## Primary Models
- **Gemini 3.1 Pro (High/Low)**: The default for complex reasoning and large-scale coding.
- **Gemini 3 Flash**: Optimized for speed and simple tasks.
- **Claude 4.6 Sonnet/Opus**: Integrated via Vertex AI for diverse reasoning styles.
- **GPT-OSS-120b**: Open-source alternative for specific logic tasks.

## Switching Models
Use the `/model` command in the TUI to switch at any time.
