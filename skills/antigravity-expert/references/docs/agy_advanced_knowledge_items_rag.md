# Antigravity Knowledge Items (RAG)

Knowledge Items are Antigravity's persistent memory system that automatically captures and organizes important insights, patterns, and solutions from coding sessions.

## What is a Knowledge Item?
A collection of related information on a specific topic. Each item contains:
- A Title and Summary.
- A collection of artifacts (e.g., generated documentation, code examples, or persistent memories of user instructions).

## Generation & Usage
- **Automatic Generation**: As you interact, Antigravity analyzes the conversation to create new Knowledge Items or update existing ones.
- **Agent Usage**: The summaries of all Knowledge Items are available to the agent at all times. When a relevant item is identified, the agent automatically studies its artifacts and applies the information to the current task.
- **Management**: You can view and manage these items via the Antigravity Agent Manager.
